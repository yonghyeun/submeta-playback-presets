# 0.4.2 — GIF defaults and shared UI

- Opening GIF creation uses the current playback position and the next five seconds. The end is capped at the video duration.
- Reopening during an operation also refreshes the default selection.
- Includes the shared React playback/GIF UI and lesson-content alignment merged since store version 0.4.0.
- Extension IDs, permissions and stored preferences are unchanged. The optional Mac companion remains 0.4.0.
