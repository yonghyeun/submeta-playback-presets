## T-201 제어 결과 양식

항목별로 변경 전 실제값, 목표값, 호출 결과, 변경 후 실제값, 화면 표시 일치 여부를 기록한다. 배속과 자막을 분리하며 호출 성공만으로 적용 성공을 판정하지 않는다.

## T-301 전환 결과 양식

두 코스 이상에서 새 요소 생성, 동일 요소 내부 교체, 빠른 연속 이동, 지연 트랙, 일시해제 종료, 재적용을 각각 기록한다.
