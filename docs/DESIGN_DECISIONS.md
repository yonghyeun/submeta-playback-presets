# 디자인 결정 · 첫 적용

2026-09-22 / P1~P4 / Submeta 개발본. 제품 스토어 버전은 0.4.0이며 이번 변경은 미배포다.

## 방향

“영상에 집중하고, 설정은 자연스럽게.” 영상을 주인공으로 두고 반복 설정은 중립색과 낮은 밀도로 표현한다. 재생 패널 기본 테마는 기존 호스트와 같은 어두운 바탕으로 정했다. 밝은 테마는 같은 의미 토큰의 대체 값으로 구현해 Storybook에서 비교한다. GIF 편집기 테마의 실제 적용과 최종 검수는 P5에 남긴다.

화면 근거는 Storybook의 `시작 → 디자인 시스템 둘러보기`와 `재생 설정` 사례에 있다. P0의 기존 화면은 `design/evidence/p0/`에 보관했다.

## 원칙을 구현한 규칙

| 원칙 | 규칙 | 확인 방법 |
|---|---|---|
| 콘텐츠 우선 | 설정 영역 제목은 본문 크기, 주요 콘텐츠와 분리되는 경계, 상태 설명은 기본 접힘 | 실제 ZIP 배치 검사, 기본 상태 이미지 |
| 예측 가능한 조작 | 버튼·선택 입력 높이 36px, 모서리 8px, 공통 포커스 표시 | 토큰 검사, 키보드 검사, 공통 요소 사례 |
| 정직한 상태 | 저장 중·저장 실패·언어 미제공·연결 실패를 문구로 표현 | 상태 사례와 접근성 검사 |
| 키보드 접근 | native input/select/button/details 유지, 체크박스 Space, 입력 Tab, 상태 Enter | 실제 브라우저 키보드 검사 |
| 문맥에 맞는 테마 | 색 이름 대신 배경·본문·행동·상태의 의미를 공유 | dark/light 사례 및 시각 비교 |

## 값과 범위

- 간격: 4/8/12/16/20/24/32/40px. 모서리: 4/8/12px.
- 패널 본문 14px, 보조 문구 12px, 줄 간격 1.6. 제품 글꼴은 호스트를 상속하고 사례·시각 검사는 로컬 Noto Sans KR 5.3.0으로 고정한다.
- 기본 배경 `#19191c`, 입력 `#2b2b30`, 본문 `#f4f4f7`. 색의 원본은 `design/tokens.json`이며 제품 코드에 반복하지 않는다.
- 640px 이하에서는 설정 유지가 한 행을 차지하고 배속/CC를 두 열, 언어를 전체 폭으로 배치한다. 390/768/1100px에서 가로 넘침과 대표 상태를 검사한다.
- disabled는 의미상 비활성 상태와 함께 표시한다. 색만으로 오류를 전달하지 않는다.
- 포커스 선 두께 2px, 간격 3px. 운영체제 강제 색상 모드에서 체크박스를 기본 컨트롤로 복원한다.

## 구현 경계와 예외

`extension/ui/`는 공통 UI와 생성된 토큰, `extension/panel.js`는 browser storage·플레이어 연결 어댑터다. Storybook은 같은 렌더러에 고정 상태와 데모 콜백을 공급한다. 데모가 실제 저장·영상 연결의 증거는 아니다. 실제 동작은 제출 ZIP 기반 E2E로 확인한다.

토큰 검사는 이번에 이전한 `primitives.js`, `playback-settings.js`의 색·px 값·CSS 토큰 참조를 검사한다. 레이아웃 비율, 0, 100%, 텍스트 길이 70ch, 체크 표시 회전은 구조값으로 허용한다. 호스트에서 측정하는 `--preset-gutter`는 의도적인 제품 어댑터다. GIF 파일들의 스타일과 Storybook 설명 페이지는 현재 제품 토큰 규칙의 검사 대상이 아니다.

서로 다른 출처의 iframe에 토큰을 명시적으로 로드하는 검사를 추가했다. 열린 root·닫힌 root·light DOM의 스타일 적용은 재사용성 검사이며, GIF 편집기 통합 완료의 증거로 보지 않는다. closed root의 키보드 결과는 브라우저 접근성 트리로 읽으며 자동 axe 검사는 열린 사례에서 수행한다.

UI 사례 최초 검토에서 모바일 기본 화면, 데스크톱 오류 화면, 전체 카탈로그를 시각적으로 확인했다. Mac과 Linux는 별도 기준 이미지를 사용한다. Linux 기준은 CI의 고정 Playwright 컨테이너에서 생성된 actual을 검토한 후 저장하며, 정상 CI에서는 기준 이미지 갱신을 허용하지 않는다.
