# 플레이어 아래 설정 패널 — 0.2 구현 기록

요구 변경: 사용자가 2026-09-06에 플레이어 아래 HTML UI와 영구 저장값 기반 동작을 요청하고 구현을 승인했다. 기존 팝업 초안을 대체한다.

## 구현

- extension/에 사용자용 패널을 별도로 구성. experiments/player-poc는 이전 수동 실험 기록으로 보존.
- 영상 아래 Shadow DOM 패널: 배속, CC, 언어, 자동 적용, 항목별 상태, 현재 영상 해제/재개.
- browser.storage.local에 설정만 저장. 설정 변경 즉시 저장하고 프로필의 탭들에 반영.
- 최상위 URL/iframe 요소/src 변경과 내부 video 교체/loadstart 감지. 임시 토큰과 세대로 오래된 비동기 작업 배제.
- background 중계와 지정 frameId 사용. 페이지 postMessage는 프레임 연결 확인에만 사용하며 재생 제어와 설정값은 확장 메시지로 전달.
- 실제 video 배속과 자막 UI·TextTrack 표시 상태를 읽어 결과 검증.
- 배속/자막 항목별 10초 최대 3회 보정, 초기 15초 제한. 전체 꺼짐/일시해제는 기존 실제값을 초기화하지 않음.
- 자막 메뉴가 사용 중이면 대기. 제공되지 않는 선호 언어는 Off 처리하며 다른 언어로 임의 대체하지 않음.

## 자동 테스트

tests/extension.test.mjs: 잘못된 설정값, 언어 미제공/같은 계열 매칭, 충돌 제한, 외부 origin·잘못된 frame 거부, JSON/스크립트 문법 통과.

tests/player.test.mjs: 자동 적용 꺼짐, 실제 배속 변경, 현재 영상 해제, 다음 미디어에서 재개, 반복 충돌 중단 통과. 제어 DOM을 모의한 테스트이며 실제 사이트에서의 UI 검증과 구분한다.

## 실제 브라우저 검증

Firefox 임시 설치에서 플레이어 아래 삽입, 설정 저장, 새로고침 및 다음 영상에서 배속·한국어 재적용을 확인했다. 초기화 직후 충돌 오탐을 줄이기 위해 안정화 대기와 보정 간격을 추가했다. 자막 메뉴 없는 영상은 제어 미지원으로 표시한다. 전체 강좌 및 장시간 연속 전환 검증은 미완료다.

## 2026-09-07 디자인 수정

실제 사이트 computed style의 Px Grotesk 글꼴, #19191c 배경, #f4f4f7 글자 및 VideoDetails 여백을 기준으로 수정했다. 글꼴·색은 부모에서 상속하고 좌우 여백은 실제 강의 설명 영역에서 읽는다. 녹색 카드·큰 제목을 제거하고 배속·CC·언어를 작은 설정 줄로 구성했다. 상태·추가 동작은 접을 수 있는 details에 배치했다. 설정 저장 및 플레이어 모의 테스트 통과. 처음에는 Firefox에 이전 콘텐츠 스크립트가 남아 있었다. 확장 관리에서 확장을 다시 로드한 뒤 강의 페이지도 새로고침하여 새 디자인 반영을 확인했다. 실제 Firefox 스크린샷에서 큰 녹색 카드가 없어지고 플레이어 바로 아래에 재생 설정 유지·배속·CC·언어 줄 및 접힌 상태 항목이 표시됨을 확인했다.

## 배포 제한

일반 Firefox에서 재시작 후에도 확장이 설치 상태를 유지하려면 Mozilla 서명이 필요하다. 임시 로드는 개발 검증용이다. 이번 버전은 외부 계정 생성·배포를 수행하지 않았으며 T-601을 완료 처리하지 않는다.

## 즉시 적용

설정 유지가 꺼져 있어도 배속·CC·언어 편집은 현재 영상에 일회 적용한다. 저장 완료를 기다리지 않고 프레임에 전달하며 자신의 저장 이벤트에 의한 중복 재설정을 막는다. 설정 유지는 이후 자동 보정 여부를 결정한다. 체크박스 및 포커스 색은 중립 회색으로 변경했다. 모의 플레이어에서 설정 유지 꺼짐 상태의 즉시 배속·자막 켜기/끄기 및 자동 보정 미활성화를 검증한다.
