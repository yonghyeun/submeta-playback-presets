# 제품 요구사항 — 인계 기준선

상태: 공유 대화의 v0.1을 기반으로 하며, 2026-09-06 사용자의 요청에 따라 플레이어 아래 설정 패널과 즉시 저장 방식으로 변경했다. 최소 제어는 Firefox에서 검증됐으며 새 패널의 실사용 검수는 별도로 진행한다.

## 목적과 범위

Firefox 데스크톱의 한 프로필에서 Submeta 전체 강의에 저장한 배속과 자막 설정을 적용한다. 기존 플레이어를 사용하며 별도 플레이어를 만들지 않는다. 코스별 설정은 후속 범위다.

## 필수 기능

| ID | 요구사항 |
| --- | --- |
| FR-01 | 자동 적용 전체 켜기·끄기 |
| FR-02 | 배속 관리 여부와 값 저장. 제안 범위 0.5~2.0, 간격 0.25; 실제 지원 여부 검증 필요 |
| FR-03 | 자막 켜기·끄기·변경하지 않기 및 실제 제공 트랙 기반 언어 선택 |
| FR-04 | 최초 진입, 다음 강의, 코스 변경, 새로고침, 동일 요소 내부 영상 교체 대응 |
| FR-05 | 설정 변경 즉시 저장, 새로고침·브라우저 재시작 후 설정 유지. 지속 설치는 서명 단계 필요 |
| FR-06 | 현재 영상만 자동 적용 해제 및 재개; 다음 영상·새로고침에서 해제 종료 |
| FR-07 | 저장 상태와 실제 적용 상태 분리, 배속·자막 결과 개별 표시 |
| FR-08 | 자막 미제공·제어 미지원·권한 부족·충돌 구분, 무한 재시도 금지 |

## 동작 정책

- 자동 적용 중 저장값을 우선한다. 수동 변경은 되돌아갈 수 있음을 플레이어 아래 패널에서 안내한다. 수동 변경을 새로운 기본값으로 자동 저장하지 않는다.
- 현재 영상 해제는 탭 메모리에만 저장하고 전체 기본값은 유지한다.
- 선호 언어는 정확히 일치하는 트랙을 먼저 선택하고 같은 언어 계열의 지역 변형만 대체 후보로 삼는다. 다른 언어로 임의 대체하지 않는다.
- 언어가 없다고 확인되면 자막을 끄고 미제공 상태를 표시한다. 트랙 로딩 중에는 확인 중으로 표시한다.
- 자막 실패는 배속 적용과 재생을 막지 않는다.
- 실제값을 읽어 확인한 뒤에만 적용 성공으로 표시한다.
- 전체 기능을 끄면 자동 변경만 중단한다. 기존 배속·자막을 초기화하지 않는다.
- 설정 저장은 같은 프로필의 Submeta 탭에 공통 반영한다. 현재 영상 해제·다시 적용은 현재 탭만 대상으로 한다.
- 최초 설치: 자동 적용 꺼짐, 배속 1.0, 자막 변경하지 않기. 1.25배·영어는 예시이며 사용자 선호가 아니다.

## 화면

기존 플레이어 바로 아래에 HTML 설정 패널을 삽입한다. 전체 자동 적용, 배속(변경하지 않기 포함), CC 켜기·끄기·변경하지 않기, 실제 제공 자막 언어, 저장 및 실제 적용 상태, 현재 영상 해제·재개·다시 적용을 제공한다. 값을 변경하면 확장 전용 browser.storage.local에 즉시 저장한다. 별도 저장 버튼이나 도구 모음 팝업으로 이동할 필요가 없다. 영상 위를 덮는 패널은 제외한다.

## 제외 범위

자동 번역, 자막 생성·스타일 변경, 영상 다운로드, 로그인·DRM 우회, 화질·음량·진도 관리, 모바일·다른 브라우저 지원.

## 완료 기준 — 측정 전 목표

- 전경 탭에서 각 기능의 제어 준비 완료 후 실제값 검증까지 P95 1초 이내.
- 제어 가능한 영상 전환 30회에서 자동 적용 누락 없음.
- 사이트의 설정 초기화에 제한적으로 대응하고 반복 충돌 시 중단.
- 재생·정지·탐색·음량·전체화면을 임의로 변경하지 않음.
- 항목별 실패 구분 및 재시도 상한 준수.
- 일반 Firefox에서 서명된 패키지로 지속 설치하고 재시작 후 동작 확인.
