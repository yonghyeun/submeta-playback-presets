## R-01 실행 기록

### 환경과 초기 상태

- 일시: 2026-09-11.
- Firefox: 155.0.1, macOS.
- 코드 버전: `extension/manifest.json`의 0.2.0 작업본. 아래 SHA-256으로 정확한 파일 상태 식별.
- 강의: Foundations IV: Passing — Introduction to Passing the Guard.
- 초기 플레이어: 약 3.342초에서 일시정지, 원래 CC 메뉴 Off.
- 확장 관리 화면: **임시 확장 기능 0개**. 강의 아래 설정 패널도 없었다.
- 이 관찰은 현재 임시 확장이 없다는 증거다. 과거 제거 시점을 직접 관찰하지 않았으므로 Firefox 종료가 실제 제거 원인이었다고 단정하지 않는다.

### 수행 내용과 관찰

1. `about:debugging#/runtime/this-firefox`에서 작업 폴더의 `extension/manifest.json`을 임시 로드했다.
2. **임시 확장 기능 1개**, `Submeta Playback Preset`, 작업 폴더 경로를 확인했다.
3. 기존 강의 탭으로 돌아오자 별도 새로고침 없이 패널이 표시되었다. 저장되어 있던 **유지 ON·1.5배·한국어 CC 켜기** 설정이 나타났고 원래 플레이어 CC 메뉴도 한국어가 되었다.
4. 유지 체크를 OFF로 바꾸고 약 3.342초 위치에서 재생을 시작했다.
5. 하단 배속 메뉴에서 **2배**를 선택했다. 원래 플레이어는 계속 `Pause` 버튼을 표시했고 위치는 약 16.989초, 이후 30.758초로 진행했다.
6. 상세 상태를 펼쳐 **저장됨 / 배속: 2배 · 자동 적용 꺼짐**을 확인했다. 이는 확장이 플레이어의 실제 `video.playbackRate`를 읽어 보내는 보고값이다. 독립적인 재생 시간 비율 측정은 이번 단계에 포함하지 않았다.
7. 다음 영상으로 넘어가지 않도록 약 42.573초에서 일시정지했다.
8. **1.5배·유지 ON**을 복원했다. **배속: 1.5배 적용됨 / 자막: 한국어 활성화 확인됨**을 확인했다.
9. 키보드 탐색으로 약 **3.507초·일시정지** 상태로 되돌렸다. 초기 위치와 약 0.165초 차이가 있으며 정확한 프레임 단위 복원은 아니다.
