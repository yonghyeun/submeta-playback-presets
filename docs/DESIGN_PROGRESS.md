## 작업별 실행 기록 양식

작업을 시작할 때 아래 내용을 이 파일에 추가하거나 별도 실행 기록으로 작성하고 해당 작업의 증거 칸에 연결한다. 민감한 실제 검수 자료는 로컬 보관 위치와 비식별 요약만 기록한다.

```text
작업 ID / 시작일 / 현재 상태:
기준 커밋 / 제품 버전 / 기존 작업 변경:
수용 기준:
변경 파일과 영향 범위:
디자인 결정 / 예외:
검사 명령 / 환경 / 실행 시각 / 결과:
증거 경로:
구현 완료 / 자동 검사 완료 / 실제 검수 완료:
실패 원인 또는 미확인 범위:
다음 행동 / 차단 해제 조건:
```
