# 단계별 작업

한 단계의 변경·검증·결과 기록 후 다음 단계로 진행한다.

| 작업 | 단계 | 상태 | 완료 기준 |
| --- | --- | --- | --- |
| T-001 | 0. Git 준비 | 완료 | Git 실행, 저장소 초기화, 문서 커밋, 상태·이력 확인 |
| T-002 | 0. 요구사항 인계 | 완료 | 공유 대화 출처·PRD·설계·작업 목록 기록 |
| T-003 | 구현 도구 준비 | 미완료 | Node.js·npm 실행 확인; 코드 실험·구현 전 준비 |
| T-101 | 1. 플레이어 조사 | 미실행 | 실제 강의의 공급자·iframe·자막 렌더러·강의 식별·주 플레이어 선택 근거 기록 |
| T-201 | 2. 최소 제어 | 미실행 | 배속 읽기·변경, 트랙 조회·선택·끄기 및 실제 결과 확인 |
| T-301 | 3. 영상 전환 | 미실행 | 두 코스 이상에서 전환·동일 요소 교체와 재적용 검증 후 어댑터 확정 |
| T-401 | 4. 확장 구현 | 미실행 | 팝업·저장·자동 유지·일시해제·상태 표시와 관련 테스트 |
| T-501 | 5. 실사용 검수 | 미실행 | PRD 성능·30회 전환·실패·충돌·부작용 기준 측정 |

## 현재 환경 관찰 — 2026-09-06

- 작업 폴더는 처음에 비어 있었음. 기존 프로젝트나 Git 이력 없음.
- Command Line Tools 설치 후 Git 2.50.1 실행 확인. main 브랜치 저장소를 초기화하고 준비 문서를 최초 커밋으로 기록.
- 현재 셸 PATH에서 node와 npm을 찾지 못함. Firefox.app은 설치되어 있음. 구현 전 Node.js 개발 환경 준비 필요.
- 이전 대화의 bundle 내 커밋은 이 Mac에서 확인한 이력이 아님.
- 다음 조사에는 로그인된 실제 Submeta 강의 접근이 필요함. 계정 정보는 문서로 받거나 저장하지 않음.
