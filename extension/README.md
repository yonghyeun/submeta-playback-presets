# Playback Presets for Submeta 0.3.0

Firefox의 Submeta 강의 플레이어 **바로 아래**에 설정 패널을 추가합니다.

- 자동 적용, 배속, CC 켜기/끄기/변경하지 않기, 실제 제공 자막 언어
- 변경 즉시 `browser.storage.local`에 저장; 저장 상태와 실제 적용 상태 분리
- 다음 강의·페이지 새로고침·같은 iframe의 새 미디어에서 재적용
- 현재 영상만 해제/재개, 다시 적용, 반복 충돌 시 자동 보정 중단
- 서버·로그인 정보·영상 다운로드·원격 실행 코드 없음

## 사용

1. Firefox에서 Submeta 강의를 엽니다.
2. 플레이어 아래 설정 줄에서 배속과 CC·언어를 고릅니다.
3. 배속·CC·언어를 바꾸면 현재 영상에 즉시 적용됩니다. 다음 영상에서도 자동 유지하려면 **재생 설정 유지**를 켭니다. **저장 및 적용 상태**를 펼치면 배속·자막 결과를 확인할 수 있습니다.
4. 다음 영상에서도 저장값을 사용합니다. 잠깐 수동 조절하려면 **저장 및 적용 상태 → 현재 영상만 해제**를 누릅니다.

최초 설치는 자동 적용 꺼짐, 1배, 자막 변경하지 않기입니다. 언어 선택의 초기 한국어는 자동으로 자막을 켜는 설정이 아닙니다.

## 설치 상태

현재 개발용 버전입니다. `about:debugging#/runtime/this-firefox`의 **임시 부가 기능 로드…**에서 이 폴더의 `manifest.json` 또는 소스 ZIP을 선택합니다. 설치 후 강의 페이지를 새로고침합니다. 파일을 웹페이지처럼 열어 실행하는 방식이 아닙니다.

설정은 확장 저장소에 저장되지만 **임시 설치한 확장 자체는 Firefox 종료 시 제거됩니다.** 브라우저 재시작 후에도 설치를 유지하는 정식 패키지는 Mozilla 서명 단계(T-601)가 필요합니다. 서명되지 않은 ZIP을 영구 설치 가능한 완성품으로 안내하지 않습니다.

## 코드 구조

- `manifest.json`: 사이트 접근 및 실행 파일 등록
- `panel.js`: 플레이어 아래 HTML/CSS UI, 설정 저장, 강의/iframe 변경 탐지
- `player.js`: iframe 내부 배속·자막 제어, 검증, 이벤트 재적용 및 충돌 제한
- `background.js`: 동일 탭의 지정된 프레임으로 확장 메시지 전달
- `shared.js`: 설정 검증·언어 선택·재시도 제한

설정은 프로필의 Submeta 탭 전체에 공통입니다. 현재 영상 해제는 해당 탭에만 적용합니다. Submeta 로그인 폼에는 패널이 표시되지 않으며 비밀번호를 읽지 않습니다.

## 개발과 검증

의존성 없는 JavaScript로 구성되어 빌드 과정 없이 Firefox에 로드됩니다. TypeScript/esbuild 도입은 추후 빌드 환경과 함께 결정합니다. 자동 테스트는 Node 환경에서 `node tests/extension.test.mjs`, `node tests/player.test.mjs`로 실행할 수 있습니다(저장소 루트 기준).

지원 확인은 관찰된 Cloudflare Stream 플레이어 범위입니다. 자막 선택 시 기존 CC 메뉴가 잠깐 열렸다 닫힐 수 있습니다. 사이트 메뉴가 변경되면 제어 어댑터 수정이 필요합니다.

## 배포 후보 0.3.0

Firefox Desktop 142 이상용 비공식 보조 확장입니다. 실제 확인 버전은 macOS Firefox 155.0.1입니다. Android 및 다른 브라우저는 배포 지원 대상으로 검증하지 않았습니다. 저장 이벤트 지연으로 자막 즉시 적용이 취소되는 문제를 수정했습니다. Mozilla 서명 전 ZIP은 임시 설치용이며 정식 설치 파일이 아닙니다.
